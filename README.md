# Velocity Berita 5

Child theme portal berita untuk tema induk [Velocity](https://velocitydeveloper.com). Demo: https://berita5.velocitydeveloper.com/

## Kebutuhan

- Tema induk `velocity` (disarankan 2.7.5 ke atas).
- Plugin **Velocity Addons** (hitungan kunjungan `hit` untuk berita populer).
- **Tidak butuh Kirki** sejak 1.2.0. Semua pengaturan ada di *Appearance › Customize › Berita* (Customizer bawaan WordPress).

## Pembaruan dari versi Kirki (≤ 1.1.0)

Nama pengaturan tidak berubah (`color_theme`, `image_iklan_*`, `link_iklan_*`, `link_sosmed_*`, `title_posts_*`, `cat_posts_*`, `sortby_posts_sidebar_2`), jadi isian lama tetap terbaca. Sesudah memperbarui, **nonaktifkan plugin Kirki** bila tidak dipakai plugin lain: selama Kirki aktif, tema induk tidak mencetak CSS warna/latarnya sendiri.

Panduan isi data: [child-theme-data-setup.md](child-theme-data-setup.md).
